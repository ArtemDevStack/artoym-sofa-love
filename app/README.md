# Саша × Маша — закрытый цифровой мир двух людей

Интерактивный cinematic-сайт истории отношений: Next.js (App Router) +
TypeScript (strict) + GSAP/ScrollTrigger + Lenis. Статический экспорт —
работает без сервера.

## Запуск

```bash
npm install
npm run dev      # разработка → http://localhost:3000
npm run build    # статический экспорт → dist/
```

`dist/` можно раздавать любым статическим хостингом.

## Вход

PIN по умолчанию: **1402** (день и месяц начала отношений, ДДММ).

## Где менять контент

Весь личный контент — в одном файле: **`src/data/relationship.ts`**.

| Что | Где |
|---|---|
| Имена, дата начала отношений | `relationship` |
| PIN-код и подсказка | `access` |
| Хронология «Как всё началось» | `timeline` |
| Стопка распечатанных фото | `stackPhotos` |
| Кадры киноплёнки | `filmFrames` |
| Фотографии коллажа | `collagePhotos` |
| Цифры («Наши цифры») | `stats` (`auto-days` считается от даты) |
| Места на абстрактной карте (x/y в %) | `places` |
| «Только мы поймём» | `artifacts` |
| Причины любви | `reasons` |
| Письма «Открой, когда…» | `letters` |
| Песня | `song` |
| 7 секретов и подсказки | `secrets` |
| Скрытая финальная сцена | `secretFinal` |
| Финальное письмо (по строкам) | `loveLetter` |
| Планы на будущее | `futurePlans` |

Типы сущностей — `src/types/relationship.ts`.

## Куда загружать фотографии

`public/images/couple/01.jpg … 20.jpg` — имена файлов соответствуют
путям в data-файле. Пока файла нет, на его месте показывается
эстетичный плейсхолдер с номером кадра. Форматы: JPG/WebP/AVIF,
желательно ≤ 400 КБ на кадр.

## Куда положить музыку

`public/audio/our-song.mp3` — замените лежащий там тихий
ambient-плейсхолдер на «вашу» песню. Если файла нет, плеер
автоматически скрывается. Звук включается только по действию
пользователя (autoplay policy не нарушается), плеер —
в правом нижнем углу.

## PIN → server-side

Проверка PIN сейчас mock (`src/lib/auth.ts` → `verifyPin`).
Чтобы перенести на сервер, замените тело функции на `fetch('/api/verify')`
или Server Action — сигнатура и вызовы менять не нужно.

## Секреты (7 штук)

Спрятаны в секциях: intro (звезда), timeline (дата 14.02), photo stack
(пометка ✎), film strip (кадр 24½), collage (точка между фото),
letters (марка ✶), final (точка в конце фразы). Найденные хранятся
в `localStorage` (ключ `us.secrets.v1`). Когда найдены все —
перед финалом открывается скрытая сцена `secretFinal`.

## GSAP-сцены

- **Intro** — две световые точки сближаются, вспышка, фраза,
  раскрытие первой фотографии через clip-path (pinned, scrub).
- **Timeline** — 6 полноэкранных сцен, у каждой своя механика:
  wipe / blur→sharp / curtain / slide / iris / rise + parallax кадра.
- **PhotoStack** — pinned-стопка «распечаток»: верхняя поворачивается
  и улетает, открывая следующую.
- **FilmStrip** — pinned горизонтальная киноплёнка с перфорацией,
  вертикальный скролл → горизонтальное движение.
- **MemoryCollage** — кадры влетают из разных направлений и глубины,
  деликатный tilt за курсором (desktop).
- **Counter / OurNumbers** — count-up при входе в viewport.
- **Letters** — GSAP-timeline конверта: клапан → письмо выдвигается →
  раскрывается; закрытие — обратная анимация.
- **LoveLetter** — строки из blur/opacity в резкость по скроллу.
- **Future** — фон символически светлеет (past → future).
- **FinalScene** — scale-развёртка фото, финальная фраза, кнопка
  «Пережить всё ещё раз».

## Оптимизации и доступность

- Lenis + GSAP ticker, `useGSAP` с контекстами и cleanup при unmount.
- `prefers-reduced-motion`: без Lenis, без pinned-сцен; киноплёнка
  превращается в нативную горизонтальную прокрутку, контент виден сразу.
- Мобильная версия: без custom cursor, ослабленный parallax, touch вместо hover.
- Анимации на transform/opacity/clip-path; `ScrollTrigger.refresh()`
  после входа; `invalidateOnRefresh` на горизонтальной сцене.
- next/image, lazy loading по умолчанию, priority только у hero-кадра.
- Семантический HTML, aria-labels у контролов, focus-visible, скринридер-
  подписи у плейсхолдеров фото, `robots: noindex`.
